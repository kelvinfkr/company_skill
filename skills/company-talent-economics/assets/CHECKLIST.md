# Delivery checklist (tick every box before presenting report.pdf)

- [ ] `check_phase.py <dir> --phase 10` passes
- [ ] Report and prose are written in `run.json -> language`, and that is the language the user used
- [ ] Every number in report.json carries a claim type (observed_fact / derived_metric / assumption / inference / reconstruction, or this locale's labels)
- [ ] No `TODO`, `{placeholder}` or unticked box left in report.json or analysis_notes.md
- [ ] Every Tier E number appears only as calibration, never alone behind a headline metric
- [ ] Charter section uses the charter/articles term from glossary.md, status tagged original / official_summary / reconstructed
- [ ] Career section says "observed transition shares", never "promotion probability", unless the true denominator is known
- [ ] TC definition (pre-tax, currency, equity price basis) stated in meta.threshold; FX rate and date stated if converted
- [ ] Affordability checked: payroll-envelope deviation within +/-10%, or the substitute TC/revenue ratio justified in Chain 9
- [ ] If the run is provisional, the report says so on the cover and no figure is presented as measured
- [ ] PDF visually inspected: no clipped tables, no tofu boxes in the report's script, headings not orphaned
- [ ] Deliver: report.pdf first, then the bundle directory path
