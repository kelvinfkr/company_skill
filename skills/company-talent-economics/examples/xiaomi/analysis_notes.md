# analysis_notes.md — 小米集团 FY2025（分析日 2026-08-24）

## Chain 1 payroll envelope
- 雇员福利开支 E = 304.7 亿（披露，附注 3）；SBC S = 53.65 亿（披露，非 IFRS 调节表）
- E_c = 251.0 亿；雇主社保/公积金按 18% → 现金薪酬 ≈ 212.8 亿
- 人均现金 ≈ 212.8 亿 / 56,531 ≈ 37.6 万；人均 SBC ≈ 9.5 万（会计口径下限）
- 模型需复现的目标：现金 + SBC ≈ 266 亿（±10%）

## Chain 2 workforce decomposition
- 披露：56,531 全职；大陆 53,901；研发 25,457
- 一线：门店约 18,000 家但多为合作/加盟，自营员工估 8-10k；汽车工厂+交付中心估 4-6k；客服/物流 1-2k → 一线 12.5-16.5k（mode 14.4k）
- 非研发专业岗 = 56.5k − 25.5k − 14.4k − 2.6k 境外 ≈ 14.1k
- 金字塔先验 + 锚点：≥16 级人群模型 ≈ 16,800 vs 持股雇员 16,572（吻合）；2025 年授股人次 ≈ 9.7k

## Chain 3 level → TC
- 职级表来源脉脉/CSDN 2024（Tier E）：13 级 25.6 万 … 18 级 135 万 … 19 级 252 万
- 老化调整：2025 薪酬费用 +33% vs 人数 +≈16% → 各级现金 +5-10%
- 股份年化：2025-11 授股人均 ≈ 34 万港元，按 4 年归属 ≈ 8 万元/年（普通获授者）；18 级以上按网传 60-117 万/年
- 复现检查：加权 TC ≈ 247 亿 vs 目标 266 亿 → −7.3%，在容差内
